# 칼바람 나락 5:5 추첨기

롤 칼바람 나락 5:5 내전용 랜덤 챔피언 추첨기입니다.
블루팀 5명 · 레드팀 5명, 총 10개 챔피언을 한 번에 뽑습니다.

- **최신 패치 자동 반영** — 페이지를 열 때마다 Riot Data Dragon에서 최신 버전을 확인해 챔피언 목록을 불러옵니다. 신챔피언이 나와도 코드를 고칠 필요가 없습니다.
- **중복 불가 / 중복 허용** 토글 (기본: 중복 불가)
- **다시 뽑기** · **결과 복사** (디스코드/카톡 붙여넣기용)
- PC·모바일 대응 다크 테마

## 사용

https://anchirong9-arch.github.io/lol-aram-picker/

## 데이터 출처

- Riot Data Dragon — `https://ddragon.leagueoflegends.com/api/versions.json`
- 챔피언 데이터 — `cdn/{version}/data/ko_KR/champion.json`
- 챔피언 이미지 — `cdn/{version}/img/champion/{id}.png`
